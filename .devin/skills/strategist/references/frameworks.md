# Analysis frameworks

Use these as tools. Apply the ones that fit, silently, and show only the results. Do not list frameworks for decoration.

## Contents
- Building options

- Stress-testing the decision

## Building options

**Decision-dimension matrix (morphological analysis, Fritz Zwicky).** Break the problem into independent dimensions, list choices for each, then combine one choice per dimension to form complete strategies. This is how combinations of known approaches are generated systematically instead of by intuition. Prune combinations that violate hard constraints.

**Precedent search (analogy and base rates).** Collect real past cases that match the structure of the problem. For each: what was done, outcome, why. Then state differences from the present case. Where available, use the base rate for the class of case (reference class forecasting) as the starting estimate, then adjust for specifics.

**First principles.** Strip the problem to physical, legal and economic facts. Rebuild options from those facts rather than from convention.

**Inversion.** Ask what would guarantee failure, then avoid those things. Useful for generating the unconventional option.

## Evaluating options

**Weighted criteria scoring.** Derive criteria from the objective and constraints. Weight them and justify the weights. Score each option 1 to 5 with a one-line reason. The total is a guide, not the decision; check that the ranking survives sensitivity analysis.

**Expected value with ranges.** Where outcomes can be estimated, use probability-weighted value with low, base and high cases. State the probabilities and what they rest on. Flag estimates that are guesses.

**Bottleneck analysis (Theory of Constraints, Eliyahu Goldratt).** Find the single scarcest resource or step that limits the result (time, cash, skill, access, attention). Any option that does not address the bottleneck cannot succeed.

**Opportunity cost.** What is given up by choosing each option, especially the scarce resource.

**Reversibility and option value.** Prefer choices that can be undone cheaply when uncertainty is high. Prefer commitment when speed or credibility matters and the choice is well understood. Consider staged commitment: a cheap test before full commitment.

**Regret minimization.** For personal and career decisions, compare which choice the user is likelier to regret at the end of the time horizon.

**Second-order effects.** For each option, ask what happens next, and what happens after that. Check who reacts and how.

## Stress-testing the decision

**Sensitivity analysis.** Change one key assumption at a time. Report which assumption flips the ranking. That assumption becomes the first thing to verify.

**Pre-mortem (Gary Klein).** Assume the chosen strategy failed. List the most plausible causes, then add a mitigation or a trigger for each.

**Kill criteria.** Predefine the evidence that means stop or switch, with numbers and dates.

**Red team.** State the strongest argument against the chosen option and answer it.

## Adversarial and multi-actor situations

**Actor map.** For each actor: interests, constraints, capabilities, red lines, likely moves. Identify who can veto and who can be moved.

**Game-theoretic reasoning.** Treat the other actors as rational agents with their own objectives. Ask what each does in response to each of your moves, and whether the outcome is stable. Look for coordination problems, commitment problems and incentives that differ from stated positions.

**Scenario analysis.** Build 3 to 4 scenarios from the two most important uncertainties. Test each option against each scenario. A robust option performs acceptably in all scenarios; an optimized option wins in one and fails in others. Say which kind each is.

**Historical outcome review.** For comparable conflicts or negotiations, report which approaches produced which results, from primary and scholarly sources.

## Which to use when

| Situation | Primary tools |
|---|---|
| New company or product | Precedents and base rates, bottleneck analysis, expected value ranges, staged commitment, pre-mortem |
| Geopolitical | Actor map, game-theoretic reasoning, scenarios, historical outcome review, sensitivity |
| Learning schedule | Capacity arithmetic, bottleneck analysis, prerequisite sequencing, kill criteria |
| Career | Regret minimization, reversibility, base rates for transitions, opportunity cost |
| Project | Bottleneck analysis, pre-mortem, critical path, kill criteria |
| Any high-stakes choice | Add sensitivity analysis and red team before deciding |
